## Sources

The editable sources are Markdown files, one per chapter, named `NN-short-name-vN-YYYYMMDD.md`; `00-introduction-...` is the introduction. Each starts with a `# N. Title` line (the introduction with `# Introduction`). To update the book, edit the latest copy, raise its version and date in the file name, and place the full set in `publication-inbox/presence_of_god/`. Pages are built with `python scripts/publish_book.py --book presence_of_god`.

The first version was written on 2026-10-23 from the Zotero report `\\lsuk-synrack\HomeMedia\bible_study_projects\Short_studies\presence_of_god\Zotero Report.htm` (item "logos assistant"): the Logos research assistant's answers, reference-work entries on divine presence, glory, omnipresence and the Spirit's indwelling, and about 2,400 ESV verses gathered by search. The chapters are a drafted study built from that material, not a transcription of it.
