## Sources

The editable sources are Markdown files, one per chapter, named `NN-short-name-vN-YYYYMMDD.md` (for example `01-study-guide-v1-20261011.md`). Each starts with a `# N. Title` line. To update the book, edit the latest copy, raise its version and date in the file name, and place the full set in `publication-inbox/blood_life/`. Pages are built with `python scripts/publish_book.py --book blood_life`.

The first versions (2026-10-11) were converted from the six PDFs in the Zotero export "BB-study-Blood in the bible-2026-01-22" (dated 2026-01-27), in the export's order. The wording is unchanged; run-in numbered points, labels and reference lists were set out as lists, and the tables were rebuilt as Markdown tables. The PDFs and the Zotero export are kept in `publication-archive/blood_life/2026-10-11/`.
